Private Founder Area

Enter the Founder Access Key configured on the server as FOUNDER_ACCESS_KEY. The real secret is never stored in this page.

How to set the key
1. Create a strong random secret (password manager / secret generator).
2. Put it only in server env — never in HTML, JS, or GitHub.
Local: create .env with FOUNDER_ACCESS_KEY=your_secret then npm start.
Deployed: set the same name in your host environment variables (e.g. Vercel → Project → Settings → Environment Variables).
Open this page via the running server (same origin), not file://.
